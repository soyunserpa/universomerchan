# Fotos reales de producto

Las imágenes pegadas en el chat no llegan al sistema de ficheros de la sesión,
así que la vía para hacérmelas llegar es este directorio del repositorio.

Una subcarpeta por producto:

- `treze/`      Cuaderno A5 premium
- `arconot/`    Libreta A5 clásica
- `klyro/`      Funda portátil acolchada
- `swisspeak/`  Funda portátil reciclada

Sube las fotos con el nombre que traigan. Yo las abro, identifico cada vista
(portada, contraportada, interior, detalles, zonas de marcaje) y las coloco
en la presentación.
